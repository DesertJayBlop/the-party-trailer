# The Party Trailer

Marketing site for The Party Trailer — New Zealand's mobile party hire, serving Christchurch, Queenstown/Wanaka, Auckland and Wellington.

Static HTML/CSS/JS, hosted via GitHub Pages from the repository root.

## Local preview
Open `index.html` in a browser, or run `python3 -m http.server 8000`.

## Deploy
Pushes to `main` are published automatically via GitHub Pages (Settings → Pages → Deploy from branch: main / root).
